# Source Slides Archive

This directory holds the original PowerPoint decks, exported to PDF, that the interactive
lecture notebooks in `lectures/` were originally built from.

They are kept for reference and attribution.
**They are not the teaching materials.** The notebooks in `lectures/` are.

The filenames here use the original lecture numbering from earlier terms.
That numbering does not match the current session numbers.
See the schedule table in [`../../README.md`](../../README.md) for what runs when.
